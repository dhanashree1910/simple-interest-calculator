# Simple Interest Calculator

A simple and lightweight application to calculate Simple Interest based on Principal amount, Rate of interest per year, and Time period.

## 📌 Project Overview

This project provides tools (Command Line & Interactive Web UI) to compute Simple Interest easily. It follows the standard financial formula used to determine interest earned or paid on a principal sum.

---

## 🧮 Formula

The Simple Interest is calculated using the following formula:

$$\text{Simple Interest (SI)} = \frac{P \times R \times T}{100}$$

Where:
* **P** = Principal amount (the initial amount of money)
* **R** = Rate of interest per year (%)
* **T** = Time period in years

---

## 💡 Calculation Example

Given:
* **Principal (P)** = 1000
* **Rate of Interest (R)** = 5% per year
* **Time (T)** = 2 years

$$\text{SI} = \frac{1000 \times 5 \times 2}{100} = 100$$

* **Total Amount payable/receivable** = Principal + Interest = $1000 + 100 = 1100$

---

## 🚀 How to Run

### Option 1: Web Interface (`index.html`)
1. Open `index.html` in any web browser.
2. Enter the **Principal Amount**, **Rate of Interest (%)**, and **Time (Years)**.
3. Click **Calculate** to view the simple interest and total accrued amount.

### Option 2: Python Script (`simple_interest.py`)
```bash
python simple_interest.py
```
Follow the interactive prompts to enter principal, rate, and time.

### Option 3: Shell Script (`simple-interest.sh`)
```bash
bash simple-interest.sh
```
