# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your change (`git checkout -b my-feature`).
3. Make your changes and commit them with a clear message.
4. Push your branch to your fork.
5. Open a Pull Request describing what you changed and why.

## Reporting Bugs

Open an issue and include the steps to reproduce the problem, what you expected to happen, and what actually happened.

## Suggesting Enhancements

Open an issue describing your idea and how it would improve the project.

## Code of Conduct

Please follow the rules in our [Code of Conduct](CODE_OF_CONDUCT.md) when participating in this project.
